# CS:2077 设计原稿

本目录记录本次开发中实际讨论、选用的美术稿及其来源。原始图集保留候选方案，成品使用的裁切和压缩贴图位于 [../assets/](../assets/)。

| 原稿 | 用途与选定方案 |
| --- | --- |
| [枪械与近战涂装候选](finish-studies.png) · [实装对照](finish-fit.jpg) | 从四宫格选定左上的「青花游龙」与右下的「曜金裂隙」，与原有海潮、白瓷、余烬、原厂涂装一同提供。 |
| [近战与手雷候选](gear-studies.png) · [模型试装](gear-fit.jpg) | 从上排选定「离子光谱」与「黄蜂警戒」，用于三种近战武器和高爆手雷。试装图也保留了另外两款候选。 |
| [地表材质](terrain-studies.png) | 自左上起依次为层状岩石、碎石、混凝土与湿沥青。游戏在表面纹理上叠加起伏细节与夜间光照。 |
| [击杀徽章](medal-studies.png) | 翼盾、金色机械颅面、交叉刀刃和破片手雷分别用于普通击杀、爆头击杀、近战击杀与手雷击杀。非致命头部命中另用小型头盔图形。 |
| [爆炸与烟尘](blast-studies.png) | 上排是白热核心与橙色火团，下排是烟与尘。程序负责粒子运动、压力波和局部照明。 |
| [封面角色原始渲染](operator-source.png) · [菜单成品贴图](../assets/operator.webp) | 从游戏的 GIGN 模型渲染角色，再做双色网点处理。该图是既有角色模型的衍生画面。 |

五张候选或效果图集由内置生图工具生成；选用结果来自维护者的选择。两张武器试装图由游戏模型渲染。最终菜单、地图、采购和战斗画面见[运行截图](../../docs/screenshots/)。
